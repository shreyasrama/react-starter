# react-starter

This minimal starter template aims to utilise modern web dev tooling while minimising setup and configuration files. Currently, this requires the following pre-installed:

- [Vite+ (`vp`) CLI](https://viteplus.dev/guide/#install-vp)
- [Zed](https://zed.dev/)
- [Bun](https://bun.com/docs/installation) (used as a package manager)

And has the following packages:

- React
- Vite+ (see [this link](https://viteplus.dev/guide/#getting-started) for what's included)
- Tailwind v4
